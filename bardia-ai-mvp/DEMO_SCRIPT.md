# Five-Minute Demonstration Script

## 1. Open the trainer experience - 30 seconds

Choose **Trainer Studio**.

Say:

> This is not only a renal course. The renal content is the proof-of-concept
> vertical for a general document-to-learning platform.

Point out:

- active learners and completion
- content waiting for review
- learners needing intervention

## 2. Generate a module - 90 seconds

Open **AI Module Builder**.

Keep the potassium protocol source package selected and click
**Analyze and generate**.

As the workflow runs, explain:

1. document extraction
2. boilerplate cleaning and chunking
3. concept analysis
4. instructional design
5. activity generation
6. quality review

Say:

> Each stage passes structured data to the next. After funding, a stronger model
> can replace one stage without rebuilding the whole product.

## 3. Review the output - 60 seconds

Show:

- learning objectives with source pages
- module sequence
- generated quiz and flashcards
- the ability to exclude an item
- flowchart, decision-tree, timeline, screenshot-simulation and patient-coaching recommendations
- the quality and evidence record

Say:

> AI proposes; the trainer approves. Nothing publishes automatically.

Click **Publish approved**.

## 4. View as the learner - 60 seconds

Click **Preview learner view**.

Show:

- generated objectives
- source package overview using all four learning files
- safety/eligibility gate
- potassium decision lab with worked cases
- temporary-to-ongoing flowchart
- documentation walkthrough using real source screenshots
- potassium nutrition coaching visuals
- a flippable flashcard
- one quiz question with explanation, source and diagnostic misconception

Answer at least one question incorrectly so the result screen has a meaningful
weak topic.

Then open **Work on weakness** and show:

- the learner's wrong answer
- the correct answer
- the diagnosed misconception
- a source visual
- two focused retest questions

## 5. Close the loop with analytics - 60 seconds

Return to the trainer.

Open **Students**, choose Emma Thompson, and show:

- topic mastery
- strengths
- weak areas
- explainable mistake evidence
- recommended intervention linked to the same weakness tab

Then open **Workflow** and finish with:

> The MVP already proves the full loop: trusted source package, generated
> learning, human review, learner activity, mistake diagnosis and
> performance-based remediation. The current local engine is deliberately
> simple; funding improves the intelligence rather than changing the product
> architecture.
