# eTrainer

A hemodialysis nurse onboarding prototype for WRHN — a React 18 + Vite e-learning platform covering vascular access, fluid management, infection control, and related modules.

## Running locally

```bash
npm install
npm run dev
```

Or use `./run.sh`, which does the same thing.
